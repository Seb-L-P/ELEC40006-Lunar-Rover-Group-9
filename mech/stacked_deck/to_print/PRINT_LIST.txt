WHY TWO HALVES PER DECK
================================================================================
A full deck is 204 mm long - longer than the 200 mm printer - so each deck
prints as half A + half B. The halves overlap (a half-lap) and bolt together
with 2 screws to make one flush 204 mm deck.


SUGGESTED PRINT SETTINGS (PLA)
================================================================================
  Layer height : 0.2 mm
  Perimeters   : 4
  Infill       : 25 %
  Supports     : none (all parts are designed to print without support)
  Orientation  : flat as exported, EXCEPT deck_half_B = upside-down


DO NOT PRINT
================================================================================
  deck_full.stl  - reference only (the whole 204 mm deck, too long for the bed).
                   It is not in this folder; do not print it if you see it.


ASSEMBLY (for reference - not needed to print)
================================================================================
  - 2 decks : each = deck_half_A + deck_half_B overlapped, 2x M3 screws.
  - 4 pillars between the decks : one M3 screw through each deck corner hole
    self-taps into the pillar end.
  - coil_support : screws onto one deck with 4x M3.
  Fasteners needed : M3 screws ~8-10 mm (self-tap into PLA) + a few M3 nuts.
